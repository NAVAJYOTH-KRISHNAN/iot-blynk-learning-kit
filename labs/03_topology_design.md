# Lab 3 — Design an IoT Topology

Choose a use case and draw:
1. Physical wiring topology.
2. Network topology.
3. Data-flow topology.
4. Failure-mode flowchart.

## Required decisions
- What runs locally on the MCU?
- What data goes to cloud, and at what interval?
- What happens when Wi-Fi or cloud service fails?
- What is the safe output state after reboot?
- What credentials and user permissions are required?
- How will the system be tested?

## Deliverables
- Block diagram
- Wiring diagram with pin labels and voltage notes
- Datastream table
- Bill of materials
- Firmware version and library list
- Test cases with expected and observed results
