# Hardware Preflight Checklist

- [ ] Board pinout checked for the exact board revision
- [ ] Supply voltage verified
- [ ] Common ground confirmed where required
- [ ] No 5 V signal connected directly to ESP32 GPIO
- [ ] LED has a current-limiting resistor
- [ ] High-current loads use a rated driver and suitable separate supply
- [ ] Polarity checked before power-on
- [ ] No exposed mains wiring
- [ ] Sensor tested standalone before cloud integration
