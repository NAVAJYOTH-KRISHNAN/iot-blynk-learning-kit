# Blynk Integration Checklist

- [ ] Template ID and template name match firmware
- [ ] Device token is correct and private
- [ ] Wi-Fi credentials are correct and private
- [ ] Datastream pins and types match code
- [ ] Widgets bind to intended datastreams
- [ ] Telemetry uses a controlled interval
- [ ] Incoming values are validated
- [ ] Safe startup state is defined
- [ ] Wi-Fi/cloud disconnect behavior tested
- [ ] Credentials removed from public logs and repository
- [ ] README includes board, libraries, wiring, and setup steps
