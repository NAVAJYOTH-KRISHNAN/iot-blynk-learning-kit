# IoT Glossary

- **ADC:** Analog-to-digital converter; measures an analog input within the board's supported range.
- **Actuator:** Output device such as an LED, motor, valve, or relay.
- **Datastream:** Typed channel for values exchanged with Blynk.
- **Edge computing:** Processing on or near the device rather than only in the cloud.
- **GPIO:** General-purpose input/output pin.
- **HTTP/REST:** Web API request/response patterns.
- **I2C:** Two-wire serial bus, typically SDA and SCL.
- **MQTT:** Lightweight publish/subscribe messaging protocol.
- **OTA:** Over-the-air firmware update.
- **PWM:** Pulse-width modulation used for control such as LED brightness.
- **TLS:** Cryptographic protocol used to protect network connections.
- **Topology:** Diagram showing how components or networks connect.
- **UART:** Asynchronous serial interface using TX/RX.
- **Virtual Pin:** Blynk abstraction for exchanging values independently of physical GPIO pins.
- **Wi-Fi station mode:** Device joins an existing access point/router.
